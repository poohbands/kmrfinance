# kmrfinance — แบบฟอร์มรายงานผลการดำเนินงาน ปีงบประมาณ 2570

แบบฟอร์มกรอกข้อมูลรายรับ–รายจ่ายรายเดือนของศูนย์ส่งเสริมสุขภาพแผนไทย “กมลาศรม” สำนักงานสาธารณสุขจังหวัดพิษณุโลก
ครอบคลุมเดือนตุลาคม 2569 ถึงกันยายน 2570 คำนวณยอดสะสม กำไร และยอดยาสมุนไพรคงคลังให้อัตโนมัติ

## ไฟล์ในโปรเจกต์

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | แบบฟอร์มเว็บ (ไฟล์เดียว เปิดในเบราว์เซอร์ได้ทันที) |
| `excel/fy2570-report-template.xlsx` | แบบฟอร์ม Excel สำหรับกรอกแบบออฟไลน์ (12 เดือน + ชีต Admin + สรุปปี) |

## ความสามารถ

- กรอกข้อมูลรายเดือน พิมพ์สูตรได้ เช่น `650*6+390*4`
- คำนวณกำไรแต่ละรายการ ยอดรวม ยอดสะสมตั้งแต่ต้นปี และยอดยาสมุนไพรคงคลัง
- Admin กรอก “ยอดยกมา ณ ต้นเดือนตุลาคม 2569” และ “ต้นทุนค่ายาสมุนไพรจากการขายยาสมุนไพร ณ เดือนปัจจุบัน”
- ระบบผู้ใช้ 3 ระดับ: Admin, เจ้าหน้าที่, ผู้ดูรายงาน
- เจ้าหน้าที่บันทึกร่างและส่งข้อมูล หลังส่งแล้วเดือนนั้นถูกล็อก
- Admin แก้ไขข้อมูลที่ส่งแล้วได้ (ต้องระบุเหตุผล) หรือปลดล็อกให้เจ้าหน้าที่แก้เอง
- บันทึกประวัติการแก้ไขทุกครั้ง
- ดาวน์โหลดรายงานเป็นไฟล์ Excel

## ข้อจำกัดสำคัญเมื่อเปิดจาก GitHub

เมื่อเปิด `index.html` จาก GitHub Pages หรือจากเครื่องโดยตรง แบบฟอร์มจะทำงานใน **โหมดในเครื่อง**:
ข้อมูล ผู้ใช้ และประวัติทั้งหมดเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น (localStorage)

- คนละเครื่องหรือคนละเบราว์เซอร์จะ **ไม่เห็นข้อมูลของกันและกัน**
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหายไป ควรดาวน์โหลดรายงาน Excel เก็บไว้ทุกเดือน

การแชร์ข้อมูลร่วมกันหลายคนใช้ได้เฉพาะเวอร์ชันที่เผยแพร่บน claude.ai เพราะฐานข้อมูลกลางเป็นบริการของ claude.ai
ถ้าต้องการให้เวอร์ชัน GitHub แชร์ข้อมูลกันได้ ต้องเชื่อมต่อฐานข้อมูลภายนอกเพิ่ม เช่น Firebase หรือ Supabase

## เผยแพร่ด้วย GitHub Pages

1. ไปที่ **Settings > Pages** ของ repository
2. ที่ **Source** เลือก `Deploy from a branch`
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ แบบฟอร์มจะเปิดได้ที่ `https://poohbands.github.io/kmrfinance/`

## บัญชีผู้ใช้

- บัญชี Admin หลักชื่อผู้ใช้ `admin` (รหัสผ่านแจ้งเป็นการภายใน ไม่ได้เขียนไว้ในโค้ด)
- Admin เพิ่ม แก้ไข ระงับ ลบผู้ใช้ และตั้งรหัสผ่านใหม่ได้ที่แท็บ **ผู้ใช้งาน**

### เปลี่ยนรหัสผ่าน Admin หลัก

ในโค้ดเก็บเฉพาะค่า hash (PBKDF2-SHA256, 100,000 รอบ) ไม่ได้เก็บรหัสผ่านตัวจริง
วิธีเปลี่ยน: ติดตั้ง Node.js แล้วรันคำสั่งนี้ (แทน `รหัสผ่านใหม่` ด้วยรหัสที่ต้องการ)

```bash
node -e "const c=require('crypto');const s=c.randomBytes(16).toString('hex');const h=c.pbkdf2Sync(process.argv[1],Buffer.from(s,'hex'),100000,32,'sha256').toString('hex');console.log('const ADMIN_SALT=\"'+s+'\";\nconst ADMIN_HASH=\"'+h+'\";')" "รหัสผ่านใหม่"
```

นำสองบรรทัดที่ได้ไปแทนบรรทัด `const ADMIN_SALT=...` และ `const ADMIN_HASH=...` ใน `index.html` แล้ว commit

## ข้อควรรู้ด้านความปลอดภัย

- ระบบผู้ใช้และการล็อกเดือนทำงานในเบราว์เซอร์ เหมาะสำหรับจัดระเบียบงานภายในหน่วยงาน ไม่ใช่ระบบความปลอดภัยระดับสูง
- ถ้า repository เป็นแบบ Public ใครก็อ่านโค้ดได้ ไม่ควรใช้รหัสผ่าน Admin ซ้ำกับระบบอื่น
- ห้ามอัปโหลดไฟล์ที่มีข้อมูลการเงินจริงหรือข้อมูลส่วนบุคคลขึ้น repository ที่เป็น Public
- ไฟล์ Excel ป้องกันแผ่นงานด้วยรหัสผ่าน ซึ่งป้องกันการแก้ไขโดยไม่ตั้งใจเท่านั้น
